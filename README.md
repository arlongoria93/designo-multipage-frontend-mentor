🧠 Designo Multipage Website

A responsive 7-page agency website built as part of a Frontend Mentor challenge, focused on translating high-fidelity Figma designs into a production-ready web experience using Next.js, Tailwind CSS, and Leaflet Maps API.

🚀 Live Site

👉 https://designo-multipage-frontend-mentor.vercel.app/

📸 Preview

✨ Features
Fully responsive, mobile-first layout
7-page multipage structure using Next.js routing
Pixel-perfect implementation of Figma design
Interactive map integration using Leaflet API
Form validation with user-friendly error handling
Hover states and interactive UI elements throughout
Optimized layout across mobile, tablet, and desktop screens
🛠️ Built With
Next.js – React framework for production
React – UI library
Tailwind CSS – Utility-first styling
Leaflet.js – Interactive maps
Mobile-first responsive workflow
🧩 What I Learned

This project helped me strengthen:

Structuring multi-page applications using Next.js routing
Translating Figma designs into production-level UI
Building responsive layouts with Tailwind CSS efficiently
Integrating third-party APIs (Leaflet maps)
Managing reusable layout patterns across multiple pages
Improving UI consistency across breakpoints
🧠 Challenges & Solutions
🔹 Multi-page layout consistency

Maintaining consistent layout across 7 pages required reusable components and a structured layout system in Next.js.

🔹 Responsive design precision

Achieving pixel-perfect responsiveness required careful breakpoint tuning and iterative testing across devices.

🔹 Map integration

Integrating Leaflet required handling client-side rendering correctly within Next.js to avoid SSR issues.

📈 Future Improvements

If revisiting this project, I would:

Improve accessibility (ARIA roles, landmarks, keyboard navigation)
Refactor repeated UI into more reusable components
Enhance performance (image optimization + Lighthouse tuning)
Expand form validation with more robust UX feedback
Add animations for smoother page transitions
